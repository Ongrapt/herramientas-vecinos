# Herramientas para vecinos

Páginas sencillas, sin cuenta ni contraseña, para que cualquier vecino ayude a levantar datos del condominio. Están aparte de Leger: no tocan la app.

- **marcar/**: «Marca dónde está». El vecino se para junto a un elemento (poste, árbol, transformador…), toca su ícono y el celular guarda el punto GPS. Al final envía la lista por WhatsApp (formato `tipo;zona;casa;lat;lon;precision_m;hora`) para cargarla al mapa de Leger.

Se publican con GitHub Pages (rama `main`, carpeta raíz).
